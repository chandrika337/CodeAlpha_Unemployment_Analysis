# Unemployment Analysis with Python

This project analyzes unemployment data in India using Python. I cleaned the dataset, explored unemployment trends, and created visualizations to understand how unemployment changed across regions, areas, months, and years.

## What I Did

* Cleaned and prepared the unemployment dataset
* Explored unemployment rates across different regions
* Compared **Rural vs Urban** unemployment
* Analyzed monthly and yearly trends
* Compared unemployment rates before and during the **COVID-19 period**
* Created graphs and saved them as PNG files

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Key Finding

The analysis showed a noticeable increase in the average unemployment rate during the COVID-19 period compared with the period before March 2020.
